# REMIP Frontend — Milestone 2

Il frontend (Next.js + React + TypeScript + Tailwind + shadcn/ui + Recharts +
MapLibre GL) è pianificato per la **Milestone 2** (vedi `../docs/PLAN.md` §9).
Questa directory è un placeholder intenzionale e documentato: in M1 l'interfaccia
di verifica è la documentazione OpenAPI interattiva su
`http://localhost:8000/docs`.

Pagine previste in M2: landing, registrazione/login, onboarding, dashboard di
zona, ricerca immobili, dettaglio immobile, watchlist, centro notifiche
(dark/light mode, mobile-first, accessibile). La mappa interattiva arriva in M3.
